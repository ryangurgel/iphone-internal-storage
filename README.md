# Pra Duda

A pasta [Pra Duda](Pra%20Duda) contém 385 arquivos do álbum do iPhone em qualidade original, prontos para baixar individualmente.

Os 76 vídeos acima de 100 MiB estão na [release de vídeos grandes](https://github.com/ryangurgel/iphone-internal-storage/releases/tag/pra-duda-videos-grandes). Cada ZIP pode ser extraído individualmente. Extraia todas as partes na mesma pasta para reunir os 76 vídeos.
